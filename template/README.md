# Release template

This directory is the user-supplied RPG Maker XP project used to build Lunetile's converted project distribution.

- Keep the original project data unchanged. Actions converts a separate copy with the freshly built DLL.
- `Game.ini` selects Standard RTP. Graphics and Audio are empty in this template; install RPG Maker XP Standard RTP before running the release.
- The original `RGSS104E.dll`, personal saves, logs, and generated files are not tracked or shipped. The release uses Lunetile's DLL.
- The engine's MIT license does not relicense the template launcher, scripts, or RPG Maker resources. Their existing terms continue to apply.
- Publish only project files and assets that may be redistributed. Do not add credentials or personal saves here.
