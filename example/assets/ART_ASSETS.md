# Portal character chip

`client/Graphics/Characters/Lunetile_Portal.png` is original art generated with the built-in `image_gen` tool on 2026-10-24. The repository source is `example/assets/Graphics/Characters/Lunetile_Portal.png`. Existing XP/RTP assets are preserved. Weapon rendering uses the equipped definition's existing RTP icon; those icons are not copied into the release.

The generated transparent RGBA sheet is 1254×1254 with four columns and four rows. XP's integer frame division uses 313×313 cells; the final two transparent edge pixels are unused. The stationary portal cycles the first row's four phases at five frames per second, scaled into a 72px cell with a fixed foot anchor. The opaque portal is about 60px tall. The PNG is used without pixel edits or resampling of the source file.

Generation prompt (built-in tool, `transparent_background=true`):

> Use case: stylized-concept. Asset type: an ORIGINAL RPG Maker XP character-chip sprite sheet for a top-down 2D fantasy MMORPG, replacing an old light-pillar portal. Create a 1024 by 1024 pixel transparent PNG sheet, EXACTLY 4 columns by 4 rows of equal 256 by 256 cells. Each cell contains one small upright oval magical doorway: a dark blue stone/metal rim, clear bright cyan and violet swirling magic inside, a tiny grounded base. Match readable 2000s RPG pixel art, crisp hard pixel clusters and dark outlines, no realism, no painting, no text or labels or visible grid. The whole outer background MUST be transparent, including all cell gutters and corners. Put each portal at the exact same position and scale inside its cell: centered x=128, lower base near y=232, complete portal within x=42..214,y=18..236. No clipping across any cell boundary. Four columns are four subtle looping animation phases with changing energy swirl/brightness; the physical rim/base remain fixed. Repeat those same four phases in all four rows because this stationary portal does not change facing direction. All 16 portals have consistent silhouettes, sizes and anchor points. No characters, weapons, environment, checkerboard, logos, UI, shadows outside the small base. This sheet will be used directly as a 4x4 character atlas and each frame will be rendered about 64 pixels tall.

The requested generation size differed from the returned size; rendering uses the actual dimensions above. The first-row opaque alpha bounds share the same vertical anchors (31..290 in each cell). The portal's travel destinations, level restrictions and server collision geometry are unchanged.
