# 파티클 효과 설정

서버를 끄고 `server/data/particles.json`과 `server/data/skills.json`을 편집한 뒤 서버와 클라이언트를 다시 실행하세요. 계정 파일은 수정하지 않습니다. 기본 프리셋은 화염·불씨·연기를 합친 `fire`, 빛·별·고리를 합친 `light`, 물방울·물결·물안개의 `water`입니다. 기본 연결은 마력 일격(burst)에 빛, 폭탄 투척(grenade)의 폭발에 화염, 마법사 1·2차 스킬에 물입니다.

## 스킬에 연결

### 바로 배울 수 있는 속성 스킬

K 스킬 창 첫 페이지에서 스킬을 선택하고 **습득 / 강화**를 누른 뒤, 배운 스킬의 아이콘이나 행을 우측 상단의 원하는 퀵슬롯으로 드래그하세요. 예를 들어 X에 화염 분출, V에 빛의 파동, F에 물보라를 배치하면 각각 다른 키로 사용할 수 있습니다. 슬롯 클릭도 지원하고 배치는 재접속 후 유지됩니다. 기존 퀵슬롯을 자동으로 덮어쓰지 않습니다.

| 스킬 / ID | 효과 | 범위 | MP | 재사용 |
|---|---|---|---|---|
| 화염 분출 / `fire_wave` | 불꽃·불씨·연기, 시전·적중 | 전방 부채꼴 3칸 | 10 | 1.4초 |
| 빛의 파동 / `light_wave` | 발광·별·고리, 시전·적중 | 직선 관통 5칸 | 10 | 1.2초 |
| 물보라 / `water_wave` | 물방울·물결·물안개, 시전·적중 | 전방 부채꼴 3칸 | 8 | 1.2초 |

세 스킬은 모든 직업이 레벨 1부터 선행 조건 없이 배울 수 있습니다. 단계당 SP 1, 최대 5단계이며 2단계부터 추가 피해가 단계당 5 증가합니다. 기본 추가 피해는 화염/빛 15, 물 12입니다. 새 캐릭터는 SP 1로 시작하므로 세 스킬을 모두 1단계 배우려면 SP 3이 필요합니다. 부족한 SP는 레벨업으로 얻으며 기존 계정의 포인트·습득 기록은 변경하지 않습니다. 선택 대상 없이 바라보는 방향을 공격하고 벽·NPC·MP·쿨다운은 서버가 검사합니다.

기존 스킬 객체에 다음 필드만 추가합니다. 전체 파일을 이 조각으로 교체하지 마세요.

```json
"particles": {"cast": "water", "hit": "water"}
```

`cast`는 서버가 사용을 승인했을 때 시전자 위치, `hit`는 실제 피해 위치에 작은 효과를 냅니다. 투척은 `"particles": {"explosion": "fire"}`로 폭발 위치에 연결합니다. 생략하거나 `null`로 둔 단계는 추가 파티클을 표시하지 않습니다. 기존 무기·시전·피격 모션은 함께 재생합니다. 피해·MP·재사용 시간·범위는 기존 서버 판정을 사용합니다.

## 새 프리셋 만들기

`particles.json`은 배열입니다. 기존 프리셋 하나를 복사하고 중복되지 않는 `id`를 붙인 뒤 스킬에서 그 ID를 참조하세요. 레이어를 최대 4개 겹칠 수 있습니다. 다음은 하나의 물방울 레이어 예입니다.

```json
{
  "id": "small_water",
  "layers": [{
    "shape": "drop", "count": 16, "emit_ms": 180, "delay_ms": 0,
    "life_ms": [350, 800], "speed": [45, 115], "angle": [-65, 65],
    "gravity": [0, 120], "spread": 8, "size": [0.55, 0.08], "spin": 40,
    "colors": [[190, 245, 255], [55, 165, 245], [30, 95, 185]],
    "blend": 0, "z": 940, "directional": true
  }]
}
```

| 필드 | 의미와 허용 범위 |
|---|---|
| `id` | 소문자 영문·숫자·밑줄 1~48자, 프리셋 최대 16개 |
| `shape` | `flame` 불꽃, `spark` 별, `smoke` 연기, `glow` 빛, `ring` 고리, `drop` 물방울 |
| `count` | 레이어당 1~48개, 프리셋 합계 최대 96개 |
| `emit_ms`, `delay_ms` | 분사 기간·시작 지연, 각각 0~1000ms. 분사 기간 0이면 한 번에 생성 |
| `life_ms` | 입자별 무작위 수명 [최소, 최대], 50~3000ms |
| `speed` | 무작위 속도 [최소, 최대], 0~240 게임 px/초 |
| `angle` | 무작위 분사 각도 [최소, 최대], -720~720도. 0=오른쪽, 90=아래 |
| `directional` | true면 분사 각도를 공격 방향에 맞춰 회전. 중력은 화면 축 유지 |
| `gravity` | [가로, 세로] 가속도, 각 -500~500 게임 px/초². 음수 세로는 위로 |
| `spread` | 생성 위치의 원형 분산 반경, 0~96 게임 px |
| `size` | 수명 시작·끝 배율, 각각 0.05~4. 원본 도형은 32×32px |
| `spin` | 회전 속도, -720~720도/초 |
| `colors` | 수명에 따라 섞을 RGB 색 1~4개. 채널 0~255, 끝으로 갈수록 투명해짐 |
| `blend` | 0=일반 혼합, 1=가산 혼합(빛·불꽃) |
| `z` | 표시 순서 0~1200. 기본 830~960, HUD보다 아래 |

최소/최대 쌍은 작은 수를 먼저 씁니다. `size`는 시작/끝이므로 줄어들거나 커져도 됩니다. 알 수 없는 필드·없는 프리셋 참조·범위 밖 숫자는 서버 시작 시 오류로 안내합니다. 파일이 없는 이전 설치는 내장 기본 프리셋으로 동작하며 계정을 덮어쓰지 않습니다.

## 성능과 범위

시간 기준 위치·중력·회전·색·크기·감쇠를 적용합니다. 카메라가 움직여도 이미 생긴 입자는 월드 위치를 유지합니다. 서버 이벤트 순번으로 중복 재생을 막고 같은 순번을 난수 시드로 사용합니다. 네트워크 도착 시간과 프레임 시점에 따라 화면상의 입자 위치는 조금 다를 수 있습니다.

여섯 도형 bitmap과 색 변화를 캐시하고 Sprite는 필요한 만큼 생성한 뒤 재사용합니다. 동시 입자 160개·분사기 24개, 분사기당 한 갱신에 새 입자 32개로 제한합니다. 한도를 넘거나 화면에서 멀리 떨어진 입자는 생략하며 밀린 효과를 한꺼번에 재생하지 않습니다. 피격은 30% 개수·55% 크기로, 폭발은 반경 배율로 표시합니다. 맵 변경 때 효과를 비우고 종료 때 소유 자원을 해제합니다.

모두 2D 화면 효과입니다. 실시간 광원·지형 화재·유체 시뮬레이션·영구 환경 파티클은 포함하지 않습니다. 실제 두 PC LAN·인터넷·장시간 부하는 별도 검증이 필요합니다.
