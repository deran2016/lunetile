# Lunetile v0.1.0-alpha.14 — XP·VXA 공용 클라이언트 최적화

표시 객체 순회·정렬과 GDI 문자 출력을 개선했습니다. 기존 변환본은 엔진 DLL만 교체하면 적용됩니다. 공개 RGSS API·그리기 순서·게임 속도·저장 형식과 MMO 서버/프로토콜/클라이언트 스크립트 패키지는 유지합니다.

## 다운로드

| 용도 | XP | VX Ace |
|---|---|---|
| 기존 변환본의 DLL 교체 | `lunetile-xp-speed-fix.zip` | `lunetile-vxa-speed-fix.zip` |
| 실행 가능한 전체 프로젝트 | `lunetile-template-xp-windows-x86.zip` | `lunetile-template-vxa-windows-x86.zip` |
| 변환·파일 해시·검증 자료 | `lunetile-template-xp-diagnostics.zip` | `lunetile-template-vxa-diagnostics.zip` |

공용 비교 수치와 전후 DLL/소스 해시는 `lunetile-client-performance-diagnostics.zip`, 배포 파일 해시는 `SHA256SUMS.txt`에 있습니다. 진단 ZIP은 실행에 필요하지 않습니다.

기존 프로젝트는 게임과 편집기를 종료한 뒤 해당 DLL만 `Game.exe` 옆에 교체하세요. 전체 템플릿으로 기존 Data나 Saves를 덮어쓰지 마세요. 두 패치에는 Data·Saves·INI·MMO 계정/프로필이 포함되지 않습니다. 원본 RGSS DLL과 RTP도 배포하지 않습니다.

전체 템플릿은 1280×720, 120Hz 로직, 기본 60FPS 출력이며 화면 설정에서 40/60/120FPS를 선택할 수 있습니다. Windows 11 x64, Microsoft Visual C++ x86 런타임, 해당 엔진의 RTP가 필요합니다(XP Standard / RPGVXAce).

## 같은 PC에서 확인한 결과

- 1,000 Sprite의 명령 생성 평균 시간 약 73–81%, 실제 출력 프레임당 Ruby 할당 약 76–79% 감소.
- 반복 문자열 처리 평균 XP 82.7%, VXA 81.1% 감소. 고유 문자열 XP 비용은 평균 4.0%·p95 7.6% 증가하여 설정한 10% 한도 안입니다.
- 1280×720 기본 맵 정지/왕복 이동 각 30초×3쌍: 후보 최소 출력 XP 119.967FPS·VXA 119.997FPS, 로직 119–121Hz, 최대 누락 XP 0.0278%·VXA 0%. 40/60FPS 속도도 확인했습니다.
- 작은 글자 추가의 업로드는 전체 Bitmap 1,228,800바이트 대신 1,144바이트였고, VXA 테두리/그림자는 1,440/1,288바이트였습니다.
- 문자열 전체 마스크 캐시는 프로세스당 128개·4MiB LRU입니다. Bitmap/Ruby 객체/GPU 포인터/GDI 핸들을 보관하지 않으며 F12·글꼴/DPI 변경에 비웁니다. 캐시를 사용하는 만큼 메모리는 소폭 증가할 수 있습니다.

이는 제공된 장면과 합성 부하의 로컬 측정입니다. CI는 별도 환경의 정확성/빌드 검사이며 같은 성능 수치를 보증하지 않습니다. FPS는 DXGI Present 제출 수로 물리적 스캔아웃과 구분합니다.

픽셀/명령 동등성, 224개 기존 VXA 타일 픽셀 비교, 저장·F12·해상도/창/전체 화면, 두 DLL의 x86/exports, 격리 MMO 두 클라이언트의 이동·채팅·전투·재접속 검사를 수행했습니다. 한글 입력은 확정 문자 주입으로 확인했으며 물리 키보드의 IME 조합 검사는 포함하지 않습니다. 상세 범위와 최초 검사 도구 실패 기록은 `docs/VALIDATION.md`에 있습니다.

이번 배포는 실험적 사전 릴리스입니다. 모든 플러그인/게임/PC의 120FPS, 장시간 내구성, 원본과 모든 픽셀·오디오의 일치는 보장하지 않습니다.
