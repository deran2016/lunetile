# Lunetile v0.1.0-alpha.13 — VX Ace rendering optimization

제공된 VX Ace 기본 템플릿의 타일 렌더링 비용을 줄인 Windows x86 실험적 릴리스입니다. 검증한 로컬 DLL과 ZIP을 그대로 첨부합니다. GitHub Actions의 별도 재빌드 아티팩트는 이 릴리스의 성능 측정 대상과 구분합니다.

## 다운로드와 적용

- `lunetile-vxa-speed-fix.zip`: 기존 alpha.10 이상 변환 프로젝트용 DLL 교체 패치. 게임과 편집기를 종료하고 프로젝트를 백업한 뒤 `Game.exe` 옆 `LunetileVXA.dll`만 교체하세요. Data·Saves·Game.ini는 포함하지 않습니다.
- `lunetile-template-vxa-windows-x86.zip`: 새 프로젝트용 전체 VXA 템플릿. 새 폴더에 풀고 Game.exe를 실행하세요. 기존 프로젝트를 이 ZIP으로 덮어쓰지 마세요.
- `lunetile-template-vxa-diagnostics.zip`: 현재 DLL의 실행·픽셀·성능·할당·메모리 결과와 전후 소스 해시 목록입니다.
- `SHA256SUMS.txt`: 위 ZIP 세 개의 SHA-256입니다.

Windows 11 x64, Microsoft Visual C++ x86 런타임과 RPG Maker VX Ace RTP가 필요합니다. RTP·원본 RGSS DLL·개인 저장·로그는 배포하지 않습니다. 전체 템플릿은 1280×720·120Hz 로직과 기본 60FPS 출력을 사용하며 게임 안에서 40/60/120FPS를 선택할 수 있습니다.

## 변경

- 임시 Rect/Hash 생성을 줄이고 타일 형상을 숫자 좌표로 캐시합니다.
- Table의 최근 64건 변경 기록으로 표시 범위의 순환 캐시를 갱신하고, 스크롤 때 새 행·열만 읽습니다. A1 애니메이션은 맵 재조회 없이 형상을 갱신합니다.
- 네이티브 하층/상층 명령을 연속된 동일 텍스처·클리핑·블렌드별 D3D 인스턴스로 제출합니다. 원래 표시 순서를 보존하며 타일 Draw는 기본 맵에서 3,936회→1회입니다.
- F12의 Ruby 재시작 경로도 네이티브 그래픽 상태를 초기화합니다. 공개 RGSS API·DLL exports·저장 형식은 유지합니다.

## 로컬 측정과 검증

D3D 배치의 비교 기준은 직전 로컬 검증 DLL(`e36ebcb4f41da0841390d3a530aeb093d140054d4721602f5b20f8b30be422de`)입니다. 같은 PC에서 기본 맵의 정지·왕복 이동을 이전/새 DLL 각각 30초×3회 측정했습니다.

| 3회 평균 | 정지 | 이동 |
| --- | ---: | ---: |
| 이전→새 제출 시간 | 0.569→0.109ms | 0.562→0.111ms |
| 제출 시간 감소 | 80.8% | 80.2% |
| 이전→새 생성＋해석＋제출 | 1.124→0.658ms | 1.110→0.656ms |
| 합계 시간 감소 | 41.5% | 40.9% |
| 진단 수집 포함 Ruby 할당 증가 | 0.58% | 0.52% |

120FPS 설정 6회 모두 약 120FPS·120Hz, 출력 누락 0회였습니다. 40/60FPS와 실제 이동 시간도 검사했습니다. 텍스처 교대로 배치 효과가 거의 없는 맵에서는 합계 평균 +0.60%, 제출 구간 +4.59%였으며 합계 p95는 개선됐습니다. GPU 비용 감소를 모든 맵에 보장하지 않습니다.

Python 85개, 픽셀 비교 224건, 인스턴스 0~100,000개와 초과 거부, Table·Bitmap 변경/GC·F12, XP/VXA 실행·저장/프로세스 재시작, x86/exports 및 창 크기·전체 화면 검사를 통과했습니다. 전체 ZIP을 새 폴더에 풀어 원본 RGSS DLL 없이 타이틀→새 게임 맵→정상 종료도 확인했습니다.

VXA DLL SHA-256: `0fa038ff862fd4c73147bbbcb42a480f3467f3836cd3862e314a5cabb397b3f6`.

FPS는 성공한 DXGI Present 제출 수입니다. 물리적 스캔아웃·장시간 내구성·모든 PC/플러그인의 120FPS는 인증하지 않았습니다. 자세한 수행 기록은 [VALIDATION.md](../VALIDATION.md)에 있습니다.
