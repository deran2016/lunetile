# Lunetile v0.1.0-alpha.15 — XP·VXA 게임 내부 브라우저

XP와 VX Ace에 공통 WebView2 브라우저 패널을 추가합니다. 웹 URL과 프로젝트 `Web/`의 HTML을 게임 화면 위에서 표시하고, Ruby에서 위치·크기·표시·탐색·포커스·수명을 제어합니다. 주소창과 도구 모음은 제공하지 않습니다.

## 다운로드와 적용

| 파일 | 용도 |
|---|---|
| `lunetile-browser-xp-demo.zip` | 원본 XP 실행기·새 DLL·자체 HTML의 실행 가능한 예제 |
| `lunetile-browser-vxa-demo.zip` | 원본 VX Ace 실행기·새 DLL·자체 HTML의 실행 가능한 예제 |
| `Lunetile.dll` | 기존 Lunetile XP 변환본의 DLL 교체 |
| `LunetileVXA.dll` | 기존 Lunetile VX Ace 변환본의 DLL 교체 |
| `lunetile-browser-diagnostics.zip` | 전후 DLL/소스 해시·성능·회귀·실패 기록·예제 화면 |
| `SHA256SUMS.txt` | 이 릴리스의 다운로드 파일 SHA-256 |

예제 ZIP은 새 폴더에 풀고 `Game.exe`를 실행하세요. 인터넷과 RTP 없이 로컬 HTML/CSS/JavaScript를 표시합니다. **Windows 11 x64, Microsoft Visual C++ x86 런타임, Microsoft Edge WebView2 Evergreen Runtime**이 필요합니다. Runtime을 자동 설치하지 않습니다.

기존 변환본은 게임과 편집기를 종료하고 백업한 뒤, 엔진에 맞는 DLL만 `Game.exe` 옆에 교체하세요. 예제 ZIP으로 기존 Data·Saves·INI를 덮어쓰지 마세요. 이전 전체 게임 템플릿은 alpha.14에 보존하며 이번 예제는 별도 브라우저 시연입니다. DLL 이름·exports/ordinal·저장 형식·120Hz 로직을 유지합니다.

```ruby
$browser = Lunetile::Browser.new(Rect.new(80, 60, 1120, 600))
$browser.load_file("Web/index.html")
# 또는 $browser.navigate("https://example.com")
```

위 Rect는 1280×720용입니다. 객체는 전역 변수나 장면 변수에 보관하세요. 생성·탐색은 비동기이며 `state`와 `error`로 상태를 확인합니다. [전체 API·오류 처리·설치 안내](../BROWSER.md)를 참고하세요.

## 동작과 보존

- 한 번에 패널 하나를 지원합니다. 기본 표시는 게임 포커스를 강제로 가져오지 않습니다. 브라우저 포커스 중 게임 입력을 차단하되 로직·타이머는 계속 진행합니다.
- X 또는 브라우저 포커스 중 Esc로 폐기합니다. F12는 패널 정리 후 게임 리셋, Alt+Enter는 게임 전체 화면으로 전달합니다.
- 프로필·쿠키는 기본 브라우저와 분리된 엔진/프로젝트별 LocalAppData 폴더에 유지합니다. 프로필·쿠키·개인 입력/방문 이력은 첨부하지 않습니다.
- 로컬 콘텐츠는 `Web/`만 가상 HTTPS 호스트에 연결합니다. 외부 프로그램 실행·다운로드·미디어 권한과 JS↔Ruby 연결은 제공하지 않습니다.
- 네이티브 패널이므로 Sprite z·Viewport 효과·게임 화면 캡처에는 포함되지 않습니다. 닫기 영역은 Flip-model 출력 위에서도 보이도록 별도 비활성 소유 표면을 사용합니다.
- 이전 작업의 XP 타일 캐시/제출 배치·VXA 타일 해석·문자 합성 개선과 배포 템플릿 스크립트 최적화 소스도 포함합니다. 기본 스크립트 최적화는 템플릿 패키저에만 적용하며 기존 게임/MMO 스크립트는 수정하지 않습니다.

## 실제 수행한 로컬 검증

검증 DLL은 XP `a299b69c138a621b844d75e21020ec596cbf37711f4a2a88418ec5e2eccc8fc9`, VXA `5bc7df0691e44480d334f66f2226fef5b9dae86f2770260928366ca6f0f23ca7`입니다. 이 릴리스는 아래 수치를 측정한 동일한 바이너리를 첨부합니다.

- Python 177개와 네이티브 보조 3개 통과. 두 DLL의 x86/exports·저장/별도 프로세스 불러오기·40/60/120FPS 속도·창/전체 화면 및 격리 MMO 두 클라이언트 회귀 통과.
- 1280×720 기본 맵의 기준/후보 정지·이동 각각 30초×3쌍, 열린 자체 HTML 정지·이동 각각 30초, 40/60FPS 닫힘/열림 각 10초를 포함한 총 44회 측정 통과.
- 120FPS 설정 후보 최소 **119.933FPS**, 로직 **119.997–120.000Hz**, 누락 최대 **0.0556%**. 미사용 전체 처리 평균 최대 **+0.19%**, p95는 증가하지 않아 +5% 한도 안입니다. FPS는 Present 제출 수이며 물리 스캔아웃과 구분합니다.
- 로컬 HTML/HTTP/HTTPS·폼·클릭·스크롤·한글 확정 입력·같은 패널 새 창 링크·권한/다운로드 차단·실패 복구·프로젝트 쿠키 유지/분리·GC/F12/종료 검사 통과.
- 초기 X 표시 실패를 수정하고 두 엔진에서 실제 X 픽셀을 확인했습니다. MMO 시험 도구의 전경/파일 잠금 실패와 첫 압축 해제의 포커스 전제 실패도 보존합니다. 마지막 압축 해제 검사는 현재 창 좌표와 실제 페이지 키보드 포커스를 확인한 뒤 Esc/F12를 한 번씩 입력했습니다. 이전 실패를 지우지 않습니다.
- 새 폴더의 실제 ZIP 실행에서 원본 RGSS DLL·RTP 없이 오프라인 페이지·Esc·재열기·F12·종료, 파일 보존·DLL 동일성·ZIP CRC를 확인했습니다. 원본·개인 파일 178개와 관련 없는 네이티브/일반 변환 소스 66개 해시를 유지했습니다.

CI의 새 소스 빌드/정확성 검사와 위 로컬 하드웨어 수치는 별개입니다. 첨부된 로컬 진단은 게시 전 검증 시점의 기록이며, 당시 `remote_published=false` 표식은 이후 릴리스 게시 상태를 뜻하지 않습니다. 자세한 범위는 [검증 문서](../VALIDATION.md)에 있습니다.

실험적 사전 릴리스입니다. 실제 물리 키보드의 한글 IME 조합·혼합 DPI 모니터 이동·물리 화면 FPS·장기 내구성·임의 사이트/플러그인의 호환성은 인증하지 않았습니다. 원본 RGSS DLL·RTP·개인 저장·브라우저 프로필은 배포하지 않습니다.
