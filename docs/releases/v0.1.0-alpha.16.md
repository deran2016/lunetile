# Lunetile v0.1.0-alpha.16

XP·VX Ace의 새 기본 프로젝트에 **조작 설정, 패드 진동, 별도 자동 저장과 백업 복구**를 추가합니다. Windows x86 실험적 릴리스입니다.

## 다운로드

| 파일 | 용도 |
|---|---|
| `lunetile-template-xp-windows-x86.zip` | 새 XP 게임 템플릿, Game.exe와 Lunetile.dll |
| `lunetile-template-vxa-windows-x86.zip` | 새 VX Ace 게임 템플릿, Game.exe와 LunetileVXA.dll |
| `lunetile-template-xp-diagnostics.zip` / `lunetile-template-vxa-diagnostics.zip` | CI 검증·변환 기록·해시 |
| `lunetile-xp-speed-fix.zip` / `lunetile-vxa-speed-fix.zip` | 기존 변환본의 DLL 업데이트. 이전 파일명 유지 |
| `SHA256SUMS.txt` | 배포 ZIP 체크섬 |

각 템플릿을 새 폴더에 풀고 **Game.exe**를 실행하세요. Windows 11 x64, Visual C++ x86 런타임과 해당 엔진의 RTP가 필요합니다. RTP·원본 RGSS DLL·개인 저장/백업/설정은 포함하지 않습니다. 브라우저를 사용하는 게임은 WebView2 Evergreen Runtime도 필요합니다.

## 변경 사항

- 타이틀/게임 메뉴의 **조작·저장**에서 키보드·XInput 버튼을 재설정하고 기본값을 복원할 수 있습니다. 설정과 장치별 버튼 안내는 두 엔진에서 공통입니다.
- 패드 진동 켜기/끄기·테스트와 전투 중 아군 피격 진동을 제공합니다. 시간 만료, 포커스 상실, 브라우저 포커스, F12와 종료 시 정지합니다.
- 자동 저장은 기존 수동 슬롯과 분리합니다. 맵 초기화/이동과 패배를 제외한 전투 종료 후 안전한 시점에 한 번 저장합니다. 저장 금지·이동·대화·이벤트/병렬 이벤트·예약 공통 이벤트·전송 중에는 기다립니다.
- 자동·수동 저장 각각에 정상 이전 버전 3개를 보관합니다. 새 파일과 이전 버전을 검사하고 임시 파일을 flush/fsync 후 교체합니다. 쓰기 실패로 현재 저장을 먼저 지우지 않습니다.
- 복구 메뉴에서 자동 저장 또는 수동 백업을 명시적으로 선택합니다. 손상 파일을 거부하고, 적용 실패 시 기존 게임 상태로 되돌립니다. 불러온 원본 파일에 덮어쓰지 않습니다.
- 손상된 개인 설정은 기본값으로 실행하고 원래 파일을 보존합니다. 원본 `Saves/Import`는 읽기 전용으로 유지합니다.

API·설정 경로·자동 저장 조건과 세부 제한은 [조작·저장 안내](../CONTROLS_SAVES.md)에 있습니다. 기존 RGSS 입력 상수, 저장 헤더/수동 슬롯, XP·VXA별 ABI는 유지합니다.

## 기존 프로젝트

기존 프로젝트와 `Saves`를 먼저 별도로 보관하세요. 새 기능 전체는 **최신 변환기로 검토된 원본을 새로운 폴더에 변환**한 뒤 사용하세요. 같은 엔진의 기존 `Saves`를 복사해 불러오기를 확인할 수 있습니다. 전체 템플릿 ZIP을 개인 프로젝트에 덮어쓰지 마세요.

DLL 교체만으로 기존 VXA 저장 보조 스크립트가 갱신되지는 않습니다. 새 메뉴/자동 저장/수동 백업을 모두 설치하려면 현재 변환 결과가 필요합니다. 사용자 수정 스크립트·MMO에 설치 호출을 임의 추가하지 마세요.

## 검증 범위

기능 검사는 XP·VX Ace의 실제 실행기에서 설정 검증/재실행, 백업 순환, 저장 교체 실패 주입, 자동 저장 안전 조건, 손상 거부, 복구와 적용 실패의 상태 복원을 확인합니다. 일반 릴리스 검사는 ABI·기존 런타임·저장 재시작·F12·창·브라우저·통신·MMO 회귀 및 출력 주기를 포함합니다. 배포 ZIP은 CRC·체크섬과 압축 해제 실행을 확인합니다.

연결된 실물 XInput 패드가 없어 물리 진동 체감·실물 핫플러그는 확인하지 않았습니다. 키/패드 값, 진동 시간/비활성 정지와 포커스 복귀 억제는 네이티브 자동 검사이며 실물 시험과 구분합니다. 전원 차단·장기 내구성·전체 게임 완주·임의 플러그인/패드·물리 화면 FPS는 인증하지 않습니다.

시험용 XInput DLL은 검사 프로세스 안에서만 사용하여 실제 엔진의 RT 매핑, 모터 값, Graphics 갱신 중 시간 만료, 버튼/스틱의 포커스 복귀 억제, F12와 종료 정지를 확인합니다. 드라이버 설치나 물리 모터 조작은 없으며 배포 게임에는 포함하지 않습니다. 별도 로컬 검사 요약이 첨부된 경우 CI 바이너리/해시와 구분해 읽으세요.
