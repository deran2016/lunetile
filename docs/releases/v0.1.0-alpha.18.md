# Lunetile v0.1.0-alpha.18

RPG Maker XP 에디터에서 변환본을 저장한 뒤에도 **Lunetile로 실행되도록** `Game.ini`의 엔진 설정을 자동으로 복원합니다. Windows x86 실험적 릴리스입니다.

## 다운로드

| 파일 | 용도 |
|---|---|
| `lunetile-template-xp-windows-x86.zip` | 새 XP 게임 템플릿, Game.exe와 Lunetile.dll |
| `lunetile-template-vxa-windows-x86.zip` | 새 VX Ace 게임 템플릿, Game.exe와 LunetileVXA.dll |
| `lunetile-template-xp-diagnostics.zip` / `lunetile-template-vxa-diagnostics.zip` | CI 검증·변환 기록·해시 |
| `lunetile-xp-speed-fix.zip` / `lunetile-vxa-speed-fix.zip` | 기존 변환본의 DLL 업데이트. 이전 파일명 유지 |
| `lunetile-xp-editor-fix.zip` | **새 파일.** 이전 XP 변환본에 넣는 에디터 저장 후 실행 복구 스크립트 |
| `lunetile-vxa-editor-fix.zip` | VX Ace 에디터 저장 후 실행 복구용 파일 |
| `SHA256SUMS.txt` | 배포 ZIP 체크섬 |

각 템플릿을 새 폴더에 풀고 **Game.exe**를 실행하세요. Windows 11 x64, Visual C++ x86 런타임과 해당 엔진의 RTP가 필요합니다. RTP·원본 RGSS DLL·개인 저장/백업/설정은 포함하지 않습니다.

## 변경 사항

- **XP 에디터 저장 후 자동 복원:** RPG Maker XP 에디터는 프로젝트를 저장할 때 `Game.ini`를 `Library=RGSS104E.dll`로 바꿉니다. 그래서 변환본이 원본 엔진으로 실행되어 `undefined method 'width' for Graphics:Module` 같은 오류가 났습니다. 이제 변환기가 첫 스크립트 `Game_Temp` 앞에 진입 코드를 넣습니다. 원본 엔진으로 실행되면 `Library=Lunetile.dll`로 고치고, 같은 인자로 `Game.exe`를 한 번 다시 실행합니다. 따라서 에디터의 테스트 플레이(`debug`)와 전투 테스트(`btest`)도 Lunetile로 실행됩니다.
- 설정을 쓴 뒤 다시 읽어 값이 맞을 때만 재실행합니다. `Game.ini`가 읽기 전용이거나 `Lunetile.dll`이 없으면 재실행을 반복하지 않고 오류를 표시합니다.
- 진입 코드는 Ruby 1.8 문법만 사용하며, Lunetile로 실행될 때는 아무 동작도 하지 않습니다. 에디터가 프로젝트 폴더에 복사한 `RGSS104E.dll`은 지우거나 바꾸지 않습니다.

## 기존 프로젝트

alpha.17 이하로 변환한 XP 프로젝트는 백업한 뒤 `lunetile-xp-editor-fix.zip`의 `LunetileEditorFix.rb`를 스크립트 편집기(F11) **맨 위**(`Game_Temp` 위) 새 항목에 붙여 넣고 저장하세요. 첫 줄 주석은 지우지 마세요. 다른 위치에 넣으면 원본 엔진이 앞의 변환된 스크립트를 먼저 해석하다가 오류를 낼 수 있습니다. 런타임 수정은 `lunetile-xp-speed-fix.zip`의 DLL로 교체하면 적용됩니다.

## 검증 범위

Python 단위 검사 224개, `verify_runtime.py --mode quick --all`(XP·VX Ace 실제 실행 35회)을 통과했습니다. 진입 코드는 Win32 API 대역으로 일반·`debug`·`btest`·쓰기 실패·재확인 불일치·실행 실패를 검사했습니다. 변환한 템플릿에 로컬 원본 `RGSS104E.dll`을 두고 `Game.exe`, `Game.exe debug`, `Game.exe btest`를 실행해 세 경우 모두 설정이 복원되고 같은 인자로 `Lunetile.dll` 프로세스가 다시 시작되는 것을 확인했습니다. 원본 DLL은 배포물에 포함하지 않습니다.

RPG Maker XP 에디터 화면에서 직접 저장하고 테스트 플레이하는 과정은 자동화하지 않았습니다. 실행 파일 이름을 `Game.exe`에서 바꾼 경우에도 같은 이름의 INI를 사용하지만 별도로 확인하지는 않았습니다.
